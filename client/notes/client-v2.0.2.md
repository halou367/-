# Brana AI v2.0.2 正式版更新说明

## 1. ProxyIP 与节点路由连接优化
- 优化 ProxyIP 直连连通性探测、IPv6 地址解析兼容与低延迟优选策略，同步更新桌面端与移动端路由模块。
- 顶部栏「反代管理」精简为无文字插头图标，完整适配日间 / 夜间主题色值。

## 2. 醍醐（Tihu）全端自动登录与跨账号共享同步
- 客户端与醍醐网页端默认预置访问密码，首次启动自动完成鉴权与样本库拉取。
- 打通桌面端（`BranaHost`）与安卓端（`BranaAndroid`）宿主级共享存储：任一账号配置或同步醍醐样本库后，客户端内其余全部账号自动共享配置与识别模型，无需重复输入密码。

## 3. 联合识别引擎与多源特征升级
- **鹈鹕 HTML / SVG 重权融合**：以鹈鹕 HTML/SVG 语法与结构指纹为主权重（协同 `/cost` 计费反推与纯净协议习惯），单列表展示 Top-6 联合识别排名。
- **开闭源思考链严格隔离**：杜绝闭源候选混入可见思考链会话，杜绝开源候选混入加密思考链会话；修复无 `/cost` 纯文本会话高分候选平局折叠问题，保持单调置信度区分。
- **全自动无感识别与中途路由检测**：进入账号静默扫描历史会话、切换对话即时核验最新一轮鹈鹕产物、精准捕获中途路由模型切换。

## 4. 抽卡面板与界面细节精炼
- **极简双模式抽卡**：精简为「极简鹈鹕速测」与「自定义提示词」两种模式，内置多语种防重短提示词池。
- **右下角紧凑「开源自停」开关**：置于抽卡卡片右下角，不压缩抽卡数量滑条；开启后新建对话抽卡遇到开源思考自动暂停并归档清理，关闭时完整生成并走 HTML 识别，「归档黑名单」始终仅归档不删除。
- **全局强度视觉统一与鹈鹕库紧凑顶栏**：顶部标签栏、聊天顶栏与左侧会话列表统一采用连字符原名格式（铁 / 铜 / 银 / 金四档色阶，无大写胶囊框）；鹈鹕库升级为单行紧凑吸顶搜索 +「厂商 → 型号 → 强度」三级联动筛选。
