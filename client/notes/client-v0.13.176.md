# Brana AI v0.13.176 正式版

## 识别引擎与双源融合升级
- **反推 API 严苛门控与三态防伪**：当计费接口未返回有效观测（无接口 / HTTP 403 / HTTP 429 / 0 条有效观测）时，严禁触发反推引擎或伪造 `99%` 候选分；不定方程反推采用严格三态（`true` / `false` / `null`），仅在真实命中整数解时标记通过。
- **零额度反推 + 价目表 P50 + 20 维习惯指纹融合**：深度对齐千面助手无额度反推与内置高纯度习惯库（296 条黄金样本 / 290 条人工确认），精准区分 `Claude Fable 5.1 (Max)`、`Muse Spark 1.3 (Max)`、`GPT-6 Sol (xHigh)`、`GPT-6 Luna (High)`、`Solar Pro 4` 等高近似模型与同族档位。
- **Battle 真值链路与防漂移加固**：绑定轮次投票防串轮、单侧重试保留 `_versionArchive` 历史气泡、完整度优先合并（已完成回复永不被空 `pending` 覆盖）、撤回修正幂等回滚（`revokeBattleLearningEvent`）、盲猜与揭晓双进度条（`prePct: null` 语义消歧）与只读查询零写盘污染。
- **左/右栏与加密云标题一致性**：修复完整加密标题（含模型名但无 `|` 分隔符）被本地旧缓存覆盖的问题；重识别与手动校准实时同步左右侧栏及云端标题。

## 线路、节点与纯净度体验优化
- **下拉即测速与实时纯净度联动**：移除「节点」「出口 IP（ProxyIP）」「地区」标题栏手动闪电测速按钮，展开下拉列表即自动触发并发测速与纯净度实时核验，杜绝下拉显示 `100%` 纯净度但选中后报高风险的不一致问题。
- **应用更改智能关窗与异常拦截**：点击「应用更改」完成线路切换后，自动核验新出口状态；正常即自动关闭配置窗口，异常则保留弹窗并明确提示原因。
- **发送前纯净度守卫**：发送消息前若检测到当前出口 IP 高风险，弹窗提示切换纯净 IP 以规避人机验证（CAPTCHA）。

## 会话连续性、防丢消息与长任务自愈
- **重启 / 崩溃队列与进行中任务恢复**：主进程 `saveDB` 原子写盘防截断，`RunningTracker` 跨重启恢复生成中会话并在后台完成时显示未读提醒，异常中断的未确认发送自动回退至发送队列 `SendQ`。
- **长任务与工具链自动续跑**：支持 `bash` 纯工具轮次与未完结回复（含空文本/思考尾巴）自动续接，隔离 429 限流退避与长任务预算。
- **工作区与预览安全**：支持 HTML/SVG 隔离窗口预览、代码文件「预览 / 代码」切换与不透明源沙箱缩略图。
