## Brana AI v2.0.0-beta.2（测试版通道）

> 本版本为 **v2.0.0-beta.2 预发布测试版**（Pre-release），聚焦模型指纹识别精度跃升、全自动无感人机验证、令牌协议注册与代理链路自愈、内联 HTML 预览卡片修复及多端流式稳定性闭环。

---

### 一、核心修复与升级

1. **聊天内联 HTML 预览卡片空白修复**：
   - 修复从历史缓存或远端同步加载对话时，因工具调用参数被截断为 `…[cached]` 导致气泡内联 HTML 预览卡片空白（而右侧抽屉预览正常）的问题。
   - 在 `load()`、`remoteSync()`、`resolvePreviewCardState()` 与 `HtmlPreview.healFileText()` 全链路自动从会话 `files` 补全完整源码，确保内联预览卡片与右侧工作区抽屉一致渲染。

2. **模型识别引擎与本机纠错样本深度融合（准确率 100% / LOO 99.6%）**：
   - 深度提取并融合本机全量真实对话特征与用户手动纠偏记录，内置指纹库升级至 `builtinRev: 185`（共 **449** 条高质量去噪样本）。
   - 修复手动纠偏样本因历史 `importedFromDiag + autoTeacher` 标记被降权问题，确保用户在界面手动纠正任意会话模型后立即以最高优先级锁定并实时反哺同家族档位超平面。
   - 强化 Gemini 4 Argon (High / Medium / Low / Max)、Gemini 3.8 / 3.7 Flash、Claude Opus 5.5 / 4.7、Sonnet 5.2 / 4.6、Haiku 4.5、GPT-6.1 / 6 Sol、Luna、Astra 等家族与档位区分度，实测本机 448 条有效会话精确匹配 **448/448 (100%)**，留一法泛化识别 **446/448 (99.6%)**，1 轮微测准确率达 **98.6%（家族 100%）**。

3. **全自动无感人机验证（CAPTCHA / reCAPTCHA / Turnstile）与原生 UI 融合**：
   - 移除外部插件残留文案，统一采用客户端原生顶栏/模态进度提示（`人机验证进行中…` -> `人机验证已完成`）。
   - 正常对话、新建会话与抽卡全链路遇到验证拦截时自动后台触发解题并在完成后自动恢复发送/抽卡，无需人工点击干预。

4. **批量/单号令牌协议注册代理自愈与失败卡片隔离清理**：
   - 修复令牌协议注册 `net::ERR_PROXY_CONNECTION_FAILED` 代理连接失败问题，支持 ProxyIP 故障自动重选与切换。
   - 新增注册中临时账号隔离标记（`provisionalReg`），批量或单号注册失败/中断时绝不污染账号转盘与列表，并自动彻底清理残留数据。

5. **流式状态同步、开源模型思考拦截与路由提示防抖优化**：
   - 修复偶发 `接收回复中` 卡住或回退、路由切换提示频繁重复弹出问题。
   - 修复开源模型第 2 轮工具调用与思考块漏识别问题，自动暂停并标注红色 `.rs-open-badge` 徽章，支持抽卡开源模型自动归档/删除。
