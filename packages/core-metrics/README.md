# Core Metrics (`@brana/core-metrics`)

Statistical distribution scoring and reference calibration module for structured numeric outputs.

## Usage

```bash
npm test
```

## Architecture

- `modeltrace-core.js`: Pure statistical distance and block histogram utilities (MIT).
- `model-probe-engine.js`: Reference dataset validation and distribution comparison engine.
- `probe-policy.js`: Calibration range and sequence completeness policies.
